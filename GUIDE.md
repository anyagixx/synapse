# Synapse — Как построить приложение с помощью AI

> **Ты никогда не писал код? Это для тебя.**
> Ты общаешься с AI через OpenCode. Synapse работает невидимо.

---

## Что такое Synapse?

Synapse даёт AI-ассистенту инструменты чтобы понимать твой проект:
- **Поиск по коду** — AI находит нужные функции мгновенно
- **Граф знаний** — AI видит связи между файлами
- **Проверка качества** — AI проверяет код перед сдачей
- **Экономия токенов** — AI тратит меньше денег на каждый запрос

**Ты не вызываешь Synapse вручную. AI сама решает когда использовать инструменты.**

---

## Установка

```bash
# 1. Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 2. OpenCode
curl -fsSL https://opencode.ai/install.sh | sh

# 3. Synapse
git clone https://github.com/anyagixx/synapse.git
cd synapse && make install
syn --version
```

---

## Твой первый проект (3 минуты)

```bash
mkdir my-notes-app
cd my-notes-app
syn init --interactive
opencode
```

Всё! Теперь внутри OpenCode просто скажи AI:
> «Сделай мне приложение для заметок с поиском по тексту»

AI сама:
- Найдёт нужный код через `semantic_search`
- Посмотрит структуру через `view_signatures`
- Проверит качество через `verify_project`
- Напишет, протестирует, исправит ошибки

---

## Как выглядит работа

```
Ты: "Добавь тёмную тему в настройки"

AI (внутри OpenCode):
  1. semantic_search("theme settings")  → нашла Settings модуль
  2. view_signatures("src/settings.rs") → посмотрела сигнатуры
  3. Пишет код...
  4. cargo check  (авто-прокси через Synapse)
  5. verify_project  → всё ок
  6. "Готово! Тёмная тема добавлена."
```

## Что ты НИКОГДА не делаешь

| ❌ Никогда | ✅ AI делает сама |
|-----------|------------------|
| Искать код | `semantic_search` |
| Читать сигнатуры | `view_signatures` |
| Проверять связи | `graphrag_query` |
| Проверять качество | `verify_project` + `review_code` |
| Следить за токенами | `token_savings` |

---

## Если что-то не работает

```bash
syn doctor    # Диагностика — покажет что не так
syn index     # Переиндексирует код
syn status    # Здоровье проекта
```

---

## 8 инструментов которые AI использует

| Инструмент | Когда AI вызывает |
|-----------|------------------|
| `semantic_search` | Перед написанием кода — найти существующее |
| `view_signatures` | Посмотреть что в файле |
| `graphrag_query` | Понять связи между модулями |
| `verify_project` | После изменений — проверить структуру |
| `review_code` | Перед коммитом — ревью |
| `project_status` | Общая картина здоровья |
| `token_savings` | Сколько сэкономлено |
| `compress_text` | Сжать большой текст |

---

## Советы

1. **Индексируй после клонирования**: `syn index`
2. **Запускай `syn doctor`** если что-то странно
3. **Смотри `syn gain`** чтобы видеть экономию
4. **Не думай о Synapse** — он работает сам
