# Synapse — Как построить приложение с помощью AI

> **Ты никогда не писал код? Это для тебя.**
> Ты просто говоришь AI что хочешь. Synapse работает невидимо.

---

## Что такое Synapse?

Synapse — это набор из 8 MCP-инструментов, которые LLM (через OpenCode) вызывает сама. Тебе не нужно ничего запускать вручную.

---

## Твой первый проект (2 минуты)

```bash
# 1. Создай папку
mkdir my-notes-app && cd my-notes-app

# 2. Установи Synapse (один раз)
syn init

# 3. Запусти AI
opencode

# 4. Скажи что хочешь
# "Сделай мне приложение для заметок с поиском по тексту"
```

**Всё.** LLM сама спросит уточнения, спроектирует архитектуру, напишет код, протестирует.

---

## Что делает `syn init`

Создаёт 4 файла в `.opencode/`:
- `opencode.jsonc` — авто-старт MCP сервера (LLM получает 8 инструментов)
- `plugins/synapse.ts` — авто-прокси shell-команд (экономия токенов)
- `rules/synapse.md` — инструкции для LLM
- `package.json` — зависимости плагина

**Никаких шаблонов, никаких требований, никакого scaffolding.** Всё это делает LLM.

---

## Как LLM использует Synapse

```
1. Ты: "Сделай приложение для заметок"

2. LLM (внутри OpenCode):
   - Спрашивает уточнения (язык, фичи)
   - Проектирует архитектуру
   - Создаёт файлы с MODULE_CONTRACT
   - Вызывает semantic_search чтобы найти похожий код
   - Вызывает view_signatures чтобы понять структуру
   - Вызывает verify_project чтобы проверить качество
   - Вызывает compress_text чтобы сжать ответы
   - Прогоняет cargo build через авто-прокси (экономия токенов)

3. Ты: "Добавь тёмную тему"
   LLM: вызывает semantic_search("theme settings"), находит код, меняет
```

---

## 8 MCP инструментов (LLM вызывает сама)

| Инструмент | Когда вызывается |
|-----------|-----------------|
| `semantic_search` | Найти существующий код |
| `view_signatures` | Посмотреть что в файле |
| `graphrag_query` | Понять связи между модулями |
| `verify_project` | Проверить контракты после изменений |
| `review_code` | Ревью перед коммитом |
| `project_status` | Общая картина здоровья |
| `token_savings` | Статистика экономии |
| `compress_text` | Сжать большой текст |

---

## CLI команды (для диагностики, редко нужны)

```bash
syn doctor    # Проверить что всё настроено
syn index     # Переиндексировать код
syn status    # Здоровье проекта
syn gain      # Сколько токенов сэкономлено
```

---

## Если что-то не работает

```bash
syn doctor    # Покажет что не так
```

---

## Советы

1. `syn init` — только один раз в начале
2. `syn doctor` — если LLM говорит что инструменты не видны
3. `syn gain` — смотреть экономию в конце сессии
4. Не думай о Synapse — он работает сам
