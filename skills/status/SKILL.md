# grace-status

Report project health across all dimensions.

## Report Sections

1. **Artifacts** — all XML files present and valid
2. **Contracts** — files with/without MODULE_CONTRACT, compliance rate
3. **Semantic Markup** — blocks with/without START/END, match rate
4. **Tests** — total, passed, failed, coverage percentage
5. **Knowledge Graph** — modules in graph vs code, consistency score
6. **Verification** — module-local, wave, phase pass rates
7. **Token Economy** — total saved, avg savings %, proxy stats
8. **500-Line Check** — any artifacts exceeding limit
9. **Next Actions** — suggested improvements
